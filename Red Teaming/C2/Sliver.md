
| Terminology      | Description                                                             |
| ---------------- | ----------------------------------------------------------------------- |
| Implants         | Payload generated by Sliver and delivered to target                     |
| Session-Implants | Real-time session, giống như meterpreter                                |
| Beacon-Implants  | Gửi một lệnh phản hồi sau một vài dây                                   |
| Aliases          | Wrapper of existing **sideloads** and **execute assembly** commands     |
| Extensions       | Shared library that **reflectively** loaded into Sliver implant process |

# Environment Configuration
Adding operators + armory (server)
```bash
new-operator -n vapour -l <LHOST> -p <PERMISSION>
multiplayer
```
Joining (client)
```bash
sudo sliver-client import <CFG_FILE>
sudo apt install mingw-w64
sudo apt install metasploit
```
Installing extension/alias (server)
```bash
armory
armory install all
armory update
```

# Listeners and Sessions
Create listener and killing jobs
```sliver
<PROTOCOL> --lport <LPORT>
http --lport 8080

jobs
jobs -k <INT>
```
Sessions/beacons
```sliver
sessions 
beacons 
use <ID>
background
```
Kill session/beacons + kill all session/beacon
```sliver
session -k <ID>
session -K

beacon -k <ID>
beacon -K
beacon rm
```
